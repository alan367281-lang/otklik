# Отклик

Раньше назывался Key Manager — переименован, чтобы не совпадать с
одноимённой чужой программой. Настройки старой версии переносятся сами.

Горячие клавиши и заготовки текста для Windows: нажал сочетание — в
активное окно вставился текст. Tauri 2 (Rust) + React.

Проект решения и этапы — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Запуск

```bash
npm install
npm run dev
```

Общая папка сборки Rust — `D:\dev\cargo-target` (переменная
`CARGO_TARGET_DIR`).

Программа живёт в трее. Настройки — `config.yaml` (путь виден в окне и
открывается из меню трея), изменения применяются сразу после сохранения.
Стартовые правила: `Alt+1` — короткий тестовый текст, `Ctrl+Alt+2` —
многострочный через буфер обмена. Пауза — `Ctrl+Alt+Pause` или трей.

## Установка

```bash
npm run build
```

Установщик появится в `D:\dev\cargo-target\release\bundle\nsis\`.
Ставится для текущего пользователя, без прав администратора. Настройки
живут отдельно от программы (`%APPDATA%\app.otklik.desktop\`) и
переживают переустановку.

## Проверки

```bash
npm run test:rust
npm run lint:rust
npm run typecheck
npm run smoke
```

`smoke` — сквозной тест при запущенной программе: на время проверки
дописывает в config.yaml свои правила (Ctrl+Alt+Shift+F7…F11) и потом
возвращает файл как был; в своём окне проверяет вставку печатью и через
буфер, возврат буфера, подстановки и {cursor}, клавиши, цепочку шагов,
сокращения («сразу», «целым словом» и что внутри слова не срабатывает).
Клавиши посылаются, только если в фокусе окно теста; во время теста не
трогайте клавиатуру и мышь (и закройте встроенный браузер Claude): при
первой потере фокуса тест останавливается.
