# Key Manager

Горячие клавиши и заготовки текста для Windows: нажал сочетание — в
активное окно вставился текст. Tauri 2 (Rust) + React.

Проект решения и этапы — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Запуск

```bash
npm install
npm run dev
```

Общая папка сборки Rust — `D:\dev\cargo-target` (переменная
`CARGO_TARGET_DIR`).

Программа живёт в трее. Настройки — `config.yaml` (путь виден в окне и
открывается из меню трея), изменения применяются сразу после сохранения.
Стартовые правила: `Alt+1` — короткий тестовый текст, `Ctrl+Alt+2` —
многострочный через буфер обмена. Пауза — `Ctrl+Alt+Pause` или трей.

## Проверки

```bash
npm run test:rust
npm run lint:rust
npm run typecheck
npm run smoke
```

`smoke` — сквозной тест при запущенной программе со стартовыми правилами:
открывает своё окно с полем ввода, нажимает сочетания и проверяет
результат и возврат буфера обмена. Клавиши посылаются, только если в
фокусе окно теста.
